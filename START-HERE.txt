NEEDLEDROP 1.1 RC1 — PASTE A YOUTUBE LINK, GET MP3s

1. Unzip this package. Open chrome://extensions in Google Chrome.
2. Turn on Developer mode > Load unpacked > select NEEDLEDROP.
   Select the folder that directly contains manifest.json.
   Do not select the ZIP, its parent folder, or the native subfolder.

Already installed? Copy the contents into the folder Chrome already loads,
replace matching files, then click Reload at chrome://extensions. Keep the
same installed extension to retain its tape shelf and extension ID.

ONE-TIME YOUTUBE SETUP (MAC)
3. Click the NEEDLEDROP toolbar icon. Expand One-time Mac setup.
4. Click Copy ID, then open Install-Mac.command from this package.
   Paste the ID when asked. This installs the local downloader using Homebrew.
   If you don't have Homebrew, install it from https://brew.sh first.
5. Return to NEEDLEDROP and click Check connection.

If macOS won't open the script: open Terminal, type bash followed by a space,
drag Install-Mac.command into that Terminal window, then press Return.

NOW USE IT
Paste https://music.youtube.com/watch?v=gSS2IgnnBo8 and click Get MP3.
Or paste a playlist URL to save individual numbered MP3 files in order.
Files appear under ~/Downloads/NEEDLEDROP. Use Open folder to find them.

Video links that also contain a playlist default to ONE VIDEO. To get their
playlist, choose Full playlist. The default cap is 100 items; max 500.
Keep Chrome running until the job finishes. Each job has its own subfolder.

This is a release candidate. Local conversion and automated checks passed;
live macOS Chrome setup and this YouTube example still need verification.
Unavailable, private, sign-in-required or DRM-protected sources may fail.

If YouTube changes break downloads: close Chrome and run Update-Mac.command.
README.md has the full instructions; TEST-REPORT.md lists exact test coverage.
